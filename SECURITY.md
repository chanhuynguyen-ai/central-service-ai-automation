# Security policy

Please do not open public issues for vulnerabilities or include real credentials in a report.
When adapting this portfolio project, configure a private security contact in your GitHub
repository and use GitHub's private vulnerability reporting feature.

The demo credentials, JWT secret, and integration key are intentionally local-only defaults.
They are not suitable for internet-facing deployment. See
[`docs/security-and-responsible-ai.md`](docs/security-and-responsible-ai.md) for implemented
controls, limitations, and the production-hardening checklist.
